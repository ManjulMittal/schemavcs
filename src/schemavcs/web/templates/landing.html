Start from your own schema

Paste CREATE TABLE / CREATE INDEX statements. From that point the schema is edited here and this tool generates the migrations — it deliberately does not read change scripts (ALTER, DROP, RENAME), because a history it did not witness cannot tell a rename from a drop plus an add.

Would rather look around first? Open the guided demo — it arrives with branches already diverged and something to merge.

Each visitor gets an isolated workspace, so nobody else's branches appear in yours. Nothing here is authenticated — it is a demo, not a place to keep a real schema.
