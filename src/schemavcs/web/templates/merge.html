Three-way merge, attribute by attribute

Two branches touching the same column merge cleanly as long as they moved different attributes. Only a genuine disagreement about one attribute stops here — and when it does, nothing is written until you choose.

Try: rename-email ← widen-email — one branch renamed users.email, the other retyped it; both survive. Then nickname-a ← nickname-b — both retyped users.nickname, which cannot be reconciled automatically.

into merge

“into” receives the merge; “merge” is the branch being brought in. The merge base is computed as the true common ancestor of the two branch histories, not the branch point.
